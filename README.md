# 🔢 Number Quest Game — *Guess Smart, Stay Classy*

Live Demo → [https://numberquestgame.netlify.app/](https://numberquestgame.netlify.app/)

---

## 🧩 What’s This Project?

A **number-guessing game** that’s both **fun** and **beautifully minimal**.
You get a random number between 1 and 100, and your mission — should you accept it — is to **guess it in as few tries as possible**.

Each attempt gives you hints:

> “Too high.”
> “Too low.”
> “✨ You nailed it!”

…and all of it happens inside a clean, responsive interface that looks way more elegant than any number game needs to be.

---

## ✨ Features

* 🎯 **Simple, intuitive gameplay** — no clutter, no confusion
* 💬 Helpful hints after every guess (because feedback should be kind)
* 🌿 **Soft UI aesthetic** — minimal colors, centered layout, calm vibe
* 🔁 Option to play again — because we know you’ll want to
* 📱 **Fully responsive** — works smoothly on every screen size
* ⚡ Built with pure HTML, CSS, and JS — lightweight & instant
